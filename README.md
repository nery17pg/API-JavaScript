# API-JavaScript

A collection of projects and exercises for practicing API integration using JavaScript.

## Description

This repository contains different projects focused on consuming APIs, making HTTP requests, handling responses, and working with asynchronous JavaScript.

## Technologies

- JavaScript
- HTML5
- CSS3
- Fetch API
- JSON

## Features

- HTTP requests (GET, POST, etc.)
- Promises and async/await
- JSON data handling
- DOM manipulation
- Error handling

## Projects

- **Rick and Morty API:** Fetching and displaying character data.
- More projects coming soon!

## Installation

```bash
git clone https://github.com/nery17pg/API-JavaScript.git
cd API-JavaScript
```
